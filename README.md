# Azure Cloud & DevOps Notes

Personal study notes for Microsoft Azure administration, cloud architecture, security, networking, storage, compute, governance, monitoring, DevOps, and technical interviews.

## What's inside

- **AZ-104 Revision Notes** — focused revision material covering Azure administration topics such as storage, networking, identity, governance, monitoring, backup, disaster recovery, and compute.
- **Azure Interview Q&A** — structured interview questions and answers ranging from Azure fundamentals to advanced Azure and DevOps scenarios, including practical examples, interview traps, keywords, and troubleshooting guidance.

The notes include explanations, comparison tables, exam tips, portal paths, CLI/PowerShell examples, architecture sketches, and links to Microsoft Learn where applicable.
