# AZ-104 Revision Notes — Reusable Prompt

Copy the prompt below and replace `[TOPIC NAME]` with any Azure service/topic.

---

## Prompt

```
I am preparing for the AZ-104 (Azure Administrator) exam. Create comprehensive revision notes for the following topic:

Topic: [TOPIC NAME]

Follow these rules strictly:

1. **Format:** Concise, pointer-based notes — NO lengthy descriptions, NO paragraphs, NO filler text
2. **Exam-Specific:** Include ONLY points relevant to AZ-104 — every concept, sub-concept, limit, default value, and comparison that could appear in the exam
3. **Tables:** Use comparison tables wherever applicable (e.g., SKU vs SKU, feature vs feature, service vs service)
4. **Portal Paths:** For every configurable item, mention the exact Azure Portal navigation path in this format:
   `Resource → Section → Sub-section → Action`
5. **Exam Tips:** Add ⚠️ EXAM TIP callouts for tricky/commonly tested points (gotchas, limits, defaults, locked settings)
6. **Step-by-Step Configuration Mind Maps:** At the end, include tree-diagram style mind maps (using │ ├── └── characters) for EVERY configuration scenario related to the topic. Each mind map must include:
   - Azure Portal path at the top
   - Every step with sub-options
   - Required RBAC roles where applicable
   - ⚠️ warnings for critical points
   - Prerequisites if any
7. **Quick-Fire Exam Points:** End with a numbered list of rapid-revision bullet points covering all key facts, limits, defaults, and gotchas
8. **Cover Everything:** Do NOT skip any sub-topic — include all features, configurations, monitoring, security, pricing key points, CLI/PowerShell commands if exam-relevant, and RBAC roles

Structure the notes with numbered sections using this order:
- What it is (brief definition)
- Key components / types
- Comparison tables (if applicable)
- Feature-by-feature details with portal paths
- Security & RBAC
- Monitoring & Alerts
- Pricing key points
- Quick-Fire Exam Points ⚡
- Step-by-Step Configuration Mind Maps 🗺️
```
